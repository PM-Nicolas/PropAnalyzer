# PropAnalyzer Reloaded

Automated Real Estate Underwriting with ESG Layer.

## Features

- PDF Extraction with Claude API
- 10-Year DCF with IRR, NPV, Equity Multiple
- Sensitivity Analysis (Cap Rate vs Vacancy)
- ESG Analysis (Energy Class, CRREM Stranding, Brown Discount)
- Renovation Recommendation

## Tech Stack

- Python, Streamlit, FastAPI
- Anthropic Claude API
- pandas, numpy_financial
